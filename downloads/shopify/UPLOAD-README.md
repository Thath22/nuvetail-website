# Nuvetail Shopify 主题 v1 · 上传与配置

这是 Shopify 主题 ZIP，沿用现有奶油绿页面。原 GitHub Pages 展示站保持独立。

## 上传
1. 下载 Nuvetail-Shopify-Theme-v1.zip，保持 ZIP，不用解压。
2. Shopify 后台 → 在线商店 Online Store → 主题 Themes。
3. 在主题库 Theme library 找到 导入主题 / 添加主题 / Import theme / Add theme。
4. 选择 上传 ZIP 文件 / Upload zip file，上传主题 ZIP。
5. 等待处理后，点击 编辑主题 / Customize / Edit theme 进入预览；先不要发布。

## 必做：绑定商品
1. 在编辑器里打开 主题设置 Theme settings（齿轮）。
2. 展开 Nuvetail · 商品与品牌。
3. 在 单瓶商品 中选择已建立的 Nuvetail 60mL 商品。
4. 确认 Shopify 商品价格是 USD 39.99，商品已对 Online Store 销售渠道可用；否则选择器/店面可能读不到该商品。
5. 保存。预览打开 Our drops，核对价格、规格、库存、加购及购物袋。

## 三瓶与五瓶组合
先用 Shopify Bundles 建立真实组合商品，设置到手瓶数 3 / 5、总价 USD 79.99 / 119.99，再在主题设置分别选中对应组合商品。
未绑定的组合会隐藏。不要把同一个单瓶商品填到三个位置：主题不会自动创建组合折扣，也不会自动替你把单瓶扣减为三瓶/五瓶。
主题从所选商品/规格读取实际价格和库存。组合默认选中第一个可售规格；如果有多个规格，商品页提供规格选择。

## 联系、政策与视频
- 设置 → 政策：填写并保存配送、退款、隐私、服务条款。页脚链接使用 Shopify 原生政策页面。
- 在线商店 → 页面：新建 Contact，handle 为 contact，主题模板选 contact。主题使用 Shopify 原生联系表单发送咨询。
- 主题设置 → 公开客服邮箱：填对外联系邮箱。
- 全球包邮文案可在主题设置关闭。文案开关不会自动创建免费运费，仍需配置 Shopify 配送区域和运费。
- 主题设置 → 品牌视频：从 Shopify 文件库选择视频，页面将出现带播放控件的视频。没有选择时隐藏。
- 主题设置可调品牌深绿、奶油背景及顶部公告。此版保留原站固定版式，尚不支持每个原站模块在编辑器内任意拖拽/改文案。

## 上线前实际验证
使用 Shopify 的测试支付模式下测试单瓶与每个启用的组合：商品价格、瓶数、真实库存扣减、配送税费、付款、订单邮件。支付账号、配送、税务和政策仍需在 Shopify 后台完成。
请先保留商店密码，在主题库预览确认后再发布。上传主题本身不修改支付设置，也不代表收款已开通。
